## Summary

This PR adds the MacSteam Ultimate CloverPit runtime foundation (U1), transforming MacSteam from a CrossOver-specific launcher into an independent open-source runtime manager and compatibility launcher for selected Windows games on macOS.

The target game is **CloverPit** (Steam App ID 3314790).

## Ultimate Architecture

MacSteam U1 introduces a layered architecture:

```
App (SwiftUI) → GameManager → RuntimeRegistry → Adapters → PrefixManager → ProcessRunner
                                         ├── ManagedWineRuntime (contract)
                                         ├── ImportedWineRuntime (user-selected)
                                         ├── SystemWineRuntime (system Wine)
                                         └── CrossOverRuntime (optional fallback)
```

Security boundaries are enforced at every layer: ExecutionBoundary, PathBoundary, SymlinkValidator, ArtifactVerifier.

## CloverPit-Only Scope

U1 focuses exclusively on CloverPit. All game-specific values go into `Sources/MacSteam/Resources/Recipes/cloverpit.json`. Core code never references CloverPit by name — only through the recipe interface.

## Runtime Contracts

New types enforce runtime artifact provenance:
- `RuntimeArtifactManifest` — schema v1 with SourceIdentity, LicenseIdentity, ArchiveIdentity
- SHA-256 verification required before installation
- License completeness enforced before loading
- All five RedistributionClass states documented

## Game Recipe Contracts

Schema v2 defines what a recipe can contain:
- No shell commands, no sudo, no arbitrary URLs, no absolute host paths
- `RecipeOperation` DSL with only allow-listed operations
- `DistributionGate` rejects bundled proprietary components
- Detection via Steam manifest (appmanifest_3314790.acf) + executable candidates

## Distribution Boundaries

```
MacSteam source:       GPL-3.0-or-later  (bundled)
Steam Client:          Proprietary       (never bundled, user-obtained)
CloverPit:             Proprietary       (never bundled, detected via Steam)
Wine:                  LGPL-2.1-or-later (adapter contract only in U1)
DXVK-macOS:            Zlib              (adapter contract only in U1)
MoltenVK:              Apache-2.0        (adapter contract only in U1)
D3DMetal/GPTK:         Apple terms       (never bundled)
Microsoft components:  Various           (not in U1)
```

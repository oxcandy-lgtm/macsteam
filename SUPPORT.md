# Support

## Community Support

- Check the [README](README.md) for usage instructions
- Search existing [GitHub Issues](https://github.com/oxcandy-lgtm/macsteam/issues)
- Open a new issue for bug reports or feature requests

## Scope

The maintainers can help with:

- Build issues
- Configuration questions
- Bug reproduction and fixes
- Feature discussions

The maintainers cannot help with:

- Steam account problems
- CrossOver licensing or installation
- Game-specific issues
- Purchase or refund requests

## Security Issues

For security vulnerabilities, see [SECURITY.md](SECURITY.md).
Do not report security issues via public GitHub issues.

# Privacy Policy

MacSteam is designed to run entirely locally on your machine.

## Data Collection

MacSteam **does not**:

- Collect telemetry
- Track usage analytics
- Upload logs remotely
- Send crash reports
- Sync data to the cloud
- Require an account
- Communicate with external servers
- Display advertisements
- Process personal data

## Local Storage

MacSteam stores configuration and logs locally at:

```
~/Library/Application Support/MacSteam/
```

This directory contains:

- **settings/** — User preferences (local only)
- **logs/** — Diagnostics logs (never uploaded)
- **state/** — Runtime state cache (local only)

## External Software Communication

When you choose to launch a game, MacSteam starts an external process (Steam, CrossOver, or a game) on your local machine.

Any communication those processes perform (e.g., Steam connecting to Valve's servers) is outside MacSteam's control and is subject to their respective privacy policies.

## Changes

If this policy changes in a way that affects data handling, the change will be clearly documented in the CHANGELOG and the policy version will be bumped.

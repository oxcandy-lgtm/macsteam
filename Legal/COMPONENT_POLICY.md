# Component Policy — MacSteam Ultimate

> **Version:** 1.0  
> **Applies to:** MacSteam Ultimate (cloverpit-u1)  
> **License:** GPL-3.0-or-later  

## 1. Source File Licensing (SPDX Headers)

All source files distributed as part of MacSteam **must** carry a valid SPDX license header matching the project's license.

- **Required header for all `.c`, `.h`, `.cpp`, `.hpp`, `.swift`, `.py`, `.js`, `.ts`, `.sh`, `.m`, `.mm`, and other authored source files:**

```c
// SPDX-FileCopyrightText: (C) 2024 MacSteam Contributors
// SPDX-License-Identifier: GPL-3.0-or-later
```

- Files generated by build tooling (e.g., Xcode-generated headers, CMake-generated config) are exempt but should note the generator in a comment.
- Configuration files (`.plist`, `.json`, `.yaml`, `.toml`) that do not contain executable logic are exempt.

## 2. Third-Party Component Tracking

All third-party components — whether source, compiled, or vendored — **must** be recorded in `component-lock.json` at the project root.

Each entry must include:

- **name:** Canonical component name
- **version:** Tag, commit hash, or version string
- **license:** SPDX license identifier
- **source:** Upstream URL
- **path:** Filesystem location within the project
- **type:** `source`, `binary`, `runtime`, `build-time`
- **attribution:** Whether copyright notice must be reproduced (YES/NO)

> ⚠️ **New components must be reviewed before addition.** See §6 below.

## 3. Runtime Artifacts Are Separate Packages

The following runtime artifacts are **not bundled** inside the MacSteam `.app` bundle. They are distributed as separate packages downloaded on demand:

| Artifact | License | Distribution Method |
|---|---|---|
| Wine (crossover-wine) | LGPL-2.1+ | Download via Wine manager |
| DXVK (DirectX → Vulkan) | zlib/libpng | Download via DXVK manager |
| MoltenVK (Vulkan → Metal) | Apache-2.0 | Bundled with Wine package |

Each runtime package has its own `component-lock.json` entry, SBOM, and integrity verification.

## 4. Proprietary Components — Never Bundled

The following components are **proprietary** and **must never be bundled** in any MacSteam distribution artifact (source archive, `.app` bundle, installer DMG, or package manager feed):

| Component | Owner | Reason |
|---|---|---|
| Steam Client | Valve Corporation | Proprietary binary; no redistribution licence |
| CloverPit | CloverPit Ltd. | Proprietary; user-obtained through Steam |
| D3DMetal | Apple Inc. | Proprietary; part of macOS |
| Game Porting Toolkit (GPTK) | Apple Inc. | Proprietary; Apple SDK agreement restricts redistribution |

Reference: [PROPRIETARY_COMPONENTS.md](./PROPRIETARY_COMPONENTS.md)

## 5. Unknown-License Components

Any component whose license cannot be determined **must be treated as forbidden** until a formal review has been completed.

- A component with no declared license is assumed to be all-rights-reserved.
- A component with a non-standard or ambiguous license must be researched and explicitly approved by the legal reviewer.
- The review outcome must be recorded in `component-lock.json` before the component can be used.

## 6. Component Review Process

Every new or updated third-party component shall follow this review pipeline:

```
    ┌─────────────────────────────┐
    │  Developer opens PR adding  │
    │  or updating a component    │
    └──────────┬──────────────────┘
               ▼
    ┌─────────────────────────────┐
    │  Update component-lock.json │
    │  with proposed entry        │
    └──────────┬──────────────────┘
               ▼
    ┌─────────────────────────────┐
    │  Legal review (licence,     │
    │  redistribution terms,      │
    │  patent grant, export law)  │
    └──────────┬──────────────────┘
               ▼
    ┌─────────────────────────────┐
    │  Approve / Request changes  │
    │  / Reject                   │
    └──────────┬──────────────────┘
               ▼
    ┌─────────────────────────────┐
    │  Merge PR → component-lock  │
    │  updated in main branch     │
    └─────────────────────────────┘
```

- Review **must** be performed by a person authorised by the project's legal contact.
- Automated license scanning (e.g., ScanCode, FOSSology) is encouraged as a first pass but does **not** replace human review.
- Components under a copyleft licence incompatible with GPL-3.0-or-later **must not** be linked statically or dynamically into MacSteam.
